## 更新頻率

訪客瀏覽器開頁時會直接讀取公開 Google Sheet，並在頁面停留期間每 60 秒更新；不需要等待 GitHub Actions 或重新部署。公開工作表全部通過欄位與內容驗證後才會一次更新畫面。首頁的竹韻公開社群動態也由瀏覽器直接讀取觀測站專用 API，完整活動時程則直接來自公開 Google Calendar。

## 資料快照

公開 CSV、生成 JSON 與觀測站近期動態的 last-good 快照隨網站原始碼保存，可從版本紀錄回復。Google Sheet 或觀測站失效、回傳不合法或沒有符合條件的資料時，前端不會替換 Hugo 輸出的備援內容。快照只由網站管理員手動更新；頁尾會區分「Repo 資料備援」與「Google Sheet 即時讀取」，後者時間是瀏覽器成功讀取時間，不是 Sheet 的最後編輯時間。

## 社史公開邊界

目前的歷史研究整理了 91 份 PDF、約 5,888 頁，但 OCR 仍是搜尋索引，手稿、照片與低品質掃描要以原始頁面和人工校對為準。網站會把民國 56–57 年視為目前最可靠的早期年代線索，不把創社月日定稿；對民國 85 年比賽名次的第二／第三名矛盾也會保留「待核」。

編年史日期欄統一使用 `YYYY/MM/DD`；同年範圍使用 `YYYY/MM/DD–MM/DD`，年份或年代範圍則使用 `YYYY 年` 或 `YYYY–YYYY 年`，歷史年代另以 `民國 X 年（YYYY）` 補充。來源標籤也使用 `YYYY/MM/DD`，避免同一批 Hermes 整理資料出現不同日期寫法。

完整報告、來源索引、名冊、通訊錄、留言簿私人內容與原始掃描由幹部／Hermes 工作區管理，不放入公開網站或公開下載入口。舊文件的場地、表格與行政規定只能作歷史參考，今日活動仍須依陽明交通大學現行規定辦理。
